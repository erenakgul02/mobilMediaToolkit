# Mobil Media Toolkit

YouTube videolarını mobil cihazlar için MP3 ve MP4 formatında indirmeye yarayan açık kaynaklı mobil uygulama.

## Uygulamayı İndir

Android telefonunuza yüklemek için aşağıdaki bağlantıya tıklayabilirsiniz:

### [Android APK İndir (Son Sürüm)](https://github.com/erenakgul02/mobilMediaToolkit/releases/latest/download/mobilMediaToolkit.apk)

Bu bağlantıya tıkladığınızda en güncel `.apk` dosyası doğrudan telefonunuza iner. Herhangi bir GitHub hesabı veya ek işlem gerekmez.

---

## Özellikler

- MP3 (ses) ve MP4 (video) formatında indirme.
- 320 kbps yüksek ses kalitesi, 1080p ve 720p video desteği.
- İndirme geçmişi sunucuda tutulmaz, tamamen cihazınızın kendi hafızasında saklanır.
- Sade, modern ve beyaz kullanıcı arayüzü.

## Geliştirici Kurulumu

Projeyi bilgisayarınızda çalıştırmak için:

### 1. Arka Uç (Python)

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### 2. Mobil Uygulama (React Native)

```bash
cd mobile
npm install
npm run android
```

Tarayıcı önizlemesi için:

```bash
npm run web
```
